# FOOTBALL ZONE — اتصال زنده با API-Football

این نسخه از API-Football (API-SPORTS) برای دریافت برنامه مسابقات، نتایج و وضعیت بازی‌ها استفاده می‌کند. کلید API فقط روی سرور محلی نگهداری می‌شود و به مرورگر فرستاده نمی‌شود.

## راه‌اندازی در ویندوز

1. Node.js نسخه 18 یا جدیدتر را نصب کن: https://nodejs.org/
2. فایل ZIP را کامل از حالت فشرده خارج کن.
3. از فایل `.env.example` یک کپی با نام دقیق `.env` بساز.
4. در فایل `.env` مقدار `APIFOOTBALL_KEY` را با کلید جدیدی که در داشبورد API-Football ساخته‌ای جایگزین کن. کلید را در سایت یا کد HTML قرار نده و برای کسی ارسال نکن.
5. روی `run.bat` دوبار کلیک کن.
6. سایت در `http://localhost:3000` باز می‌شود. پنجره سرور را تا وقتی از سایت استفاده می‌کنی باز نگه دار.

## اتصال و مسیرها

- `GET /api/health` — وضعیت پیکربندی سرور، بدون نمایش کلید
- `GET /api/matches?date=YYYY-MM-DD` — مسابقات یک روز با منطقه زمانی تهران
- `GET /api/live` — مسابقات در حال برگزاری
- `GET /api/match/ID` — خلاصه مسابقه، رویدادها، آمار تیم‌ها و ترکیب/نیمکت (در صورت ارائه توسط API)

صفحه مسابقات به‌طور خودکار هر ۶۰ ثانیه به‌روزرسانی می‌شود. جزئیات تکمیلی فقط هنگام بازکردن یک مسابقه درخواست می‌شوند تا مصرف سهمیه بی‌دلیل بالا نرود. این فاصله برای رعایت توصیه مستندات API-Football انتخاب شده است؛ داده‌ها بسته به لیگ و پلن حساب ممکن است پوشش یا تأخیر متفاوتی داشته باشند.

## نکات مهم امنیت و پوشش

- کلید API را فقط داخل فایل محلی `.env` نگه دار. این فایل نباید در ZIP عمومی یا مخزن کد منتشر شود.
- اگر کلید در تصویر یا پیام نمایش داده شده، آن را در داشبورد باطل کن و کلید تازه بساز.
- این پروژه نتایج واقعی را نمایش می‌دهد و در صورت خطا نتیجه ساختگی نشان نمی‌دهد.
- همه لیگ‌ها الزاماً پوشش زنده یکسان ندارند؛ پوشش هر لیگ به اشتراک و اطلاعاتی که API ارائه می‌کند بستگی دارد.
- این نسخه برای اجرای محلی است. برای انتشار عمومی باید سرور روی هاست امن قرار گیرد و فایل `.env` از دسترس وب خارج بماند.

## عیب‌یابی

- پیام «کلید API تنظیم نشده»: نام فایل باید `.env` باشد و مقدار `APIFOOTBALL_KEY` تنظیم شده باشد.
- خطای اعتبارسنجی: کلید جدید و فعال بودن اشتراک را در داشبورد بررسی کن.
- خطای سهمیه: تعداد درخواست‌ها را زیاد نکن؛ حافظه موقت یک‌دقیقه‌ای فعال است.
- اگر مسابقه‌ای نمایش داده نشد، ممکن است در آن تاریخ بازی نباشد یا پوشش آن رقابت در پلن حساب فعال نباشد.

## نسخه 5.2 — اصلاح جزئیات مسابقه
- نمایش رویدادها، آمار دو تیم، ترکیب اصلی و بازیکنان ذخیره در پنجره جزئیات.
- اگر API برای یک مسابقه داده‌ای ارائه نکند، همان بخش با پیام نبود داده نمایش داده می‌شود و اطلاعات ساختگی ساخته نمی‌شود.
- فایل `.env` عمداً در ZIP توزیعی قرار داده نشده است؛ پس از استخراج، از `.env.example` یک کپی با نام `.env` بساز و کلید تازه خودت را وارد کن.


## نسخه 5.3 — آماده‌سازی نصب موبایل و انتشار عمومی
- وب‌اپ قابل نصب (PWA) با manifest، آیکون‌های اختصاصی و دکمه نصب.
- Service Worker برای نگهداری پوسته سایت و بازشدن صفحه اصلی در حالت آفلاین؛ درخواست‌های API عمداً کش نمی‌شوند تا نتیجه قدیمی به‌عنوان زنده نمایش داده نشود.
- فایل `render.yaml` برای شروع استقرار Node.js روی Render؛ قبل از انتشار، مخزن خصوصی GitHub بساز، پروژه را در آن قرار بده و متغیر `APIFOOTBALL_KEY` را فقط در تنظیمات امن هاست وارد کن.
- برای نصب PWA روی گوشی، سایت باید با HTTPS منتشر شود. در اندروید از دکمه «نصب اپ» یا منوی مرورگر استفاده کن؛ در آیفون از Share → Add to Home Screen.

### پیش از انتشار واقعی
این نسخه هنوز حساب کاربری، پایگاه داده مشترک، چت، لیگ آنلاین پایدار یا اپ بومی منتشرشده در Google Play / App Store ندارد. بخش‌های نمایشی باید قبل از بازکردن عمومی به بک‌اند احراز هویت و پایگاه داده متصل شوند. PWA فعلاً راه نصب موبایلی است و جایگزین انتشار اپ بومی در فروشگاه‌ها نیست.
